# **EduFlow – Learning Management System (LMS)**  

A full-featured **Learning Management System (LMS)** built with the **MERN stack**.  
EduFlow enables instructors to create and sell courses, and learners to purchase, enroll, and track their learning journey.  
This project is scalable, modular, and designed with real-world LMS use cases in mind.  

---

## **✨ Features**  

### **For Students**
- 🔐 **Secure Authentication** – Register, Login, Logout (JWT-based)  
- 📚 **Browse & Enroll in Courses** – Filter by categories 
- 💳 **Razorpay Integration** – Seamless and secure course purchase  
- ⭐ **Star Ratings & Reviews** – Leave feedback for purchased courses  

### **For Instructors**  
- 🖋 **Create & Manage Courses** – Add descriptions, modules, lessons, and resources  
- 💼 **Course Management Dashboard** – Edit, publish, or archive courses  
- 💰 **Earnings Overview** – Track income from sold courses
- 📈 **Progress Tracking** – Track lessons completed by students 


### **Core Features**
- 🔄 **Real-time Updates** with optimized APIs  
- ⚡ **Responsive UI** – Built with React and Tailwind CSS  
- 🛡 **Secure Backend** – Node.js, Express, and JWT authentication  
- 🗄 **Scalable Database** – MongoDB with Mongoose schemas  
- 🔍 **Search & Filter** – Search by course name and filter by categories  

---

## **🛠 Tech Stack**  

| Layer | Technology |
|--------|-----------|
| **Frontend** | React, Tailwind CSS, Axios, React Router |
| **Backend** | Node.js, Express.js, Redis |
| **Database** | MongoDB (Mongoose ODM) |
| **Payment** | Razorpay Integration |
| **Authentication** | JWT (JSON Web Token) |
| **State Management** | Context API / Redux |
